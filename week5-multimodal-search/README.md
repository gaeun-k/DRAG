# 5주차 — 멀티모달 검색 시스템 구축

## 학습 목표
비전-언어 임베딩과 벡터DB를 결합해 텍스트→이미지 검색 시스템을 구현한다.

## 학습 내용
- SigLIP 임베딩을 벡터DB에 인덱싱하는 방법
- 텍스트 질의로 이미지를 검색하는 파이프라인 설계

## 과제
이미지 데이터셋 대상 텍스트→이미지 검색 데모 구현
(smol-vision 노트북 템플릿을 베이스로 구현)

## 진행 방식
전원 각자 텍스트→이미지 검색 데모를 구현해온 뒤, 세션에서 모여 디버깅 및 이슈 공유
(역할 분담 없이 각자 전체 파이프라인을 직접 구현)

## 참고자료
- [Hugging Face smol-vision 실습 노트북](https://github.com/merveenoyan/smol-vision)
- FAISS/Chroma 공식 문서 (심화 참고)

## 폴더 구조
멤버별 폴더에 각자 구현한 텍스트→이미지 검색 데모를 정리합니다.
