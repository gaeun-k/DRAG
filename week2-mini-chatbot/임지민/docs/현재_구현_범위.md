# 첨부 예제와 현재 무료 구현의 대응

2026-09-23 확장판. 이 파일이 이전 버전의 상태표보다 우선합니다.

| 첨부의 구성 | 현재 대응 | 차이·제한 |
| --- | --- | --- |
| OpenAIEmbeddings | LocalEmbeddings + EmbeddingGemma | 의미 임베딩을 로컬에서 생성, digest별 SQLite 캐시 |
| ChatOpenAI | Qwen3.5:2b + LCEL Runnable | OpenAI 호출 없음, 품질·속도는 다른 모델 |
| WebBaseLoader | 공개 URL 수집 + HTML 정제 | 주소당 5MB, 최대 5주소, 인증/JS 페이지 제외 |
| PDF/CSV/TXT/Python/Directory 로딩 | ingest.py와 data 폴더 재귀 탐색 | 글과 표는 PyMuPDF 사용, 모든 파서와 1:1 복제는 아님 |
| Character / Recursive 분할 | LangChain 해당 분할기 | Character는 긴 무구분자 조각이 기준 초과할 수 있음 |
| SemanticChunker | 로컬 임베딩 거리의 75백분위 경계 + 길이 제한 | 학습용 대체 알고리즘, 원본 experimental 클래스 자체는 아님 |
| FAISS / Chroma | 둘 다 선택 가능 | 메모리 인덱스, 재시작 시 다시 생성 |
| BM25 / Ensemble / MMR / MultiQuery | BM25Okapi, reciprocal-rank 합산, MMR, 로컬 다중질문 | 한국어 어절+2글자 조각 토큰, 형태소 분석기는 아님 |
| similarity_score_threshold | 거리에서 관련성 점수로 변환 후 기준 적용 | 정답 확률이 아니며 자료마다 기준 보정 필요 |
| RunnableWithMessageHistory | 실제 해당 클래스로 세션별 기록 | 최근 3회 유지, 메시지는 길이를 제한, 검색 질문도 재작성 |
| MultiVectorRetriever 멀티모달 | 이미지 설명 검색 → doc_id로 원본 이미지 연결 → 모델 입력 | 원본 클래스 대신 같은 연결 구조 직접 구현. 답변당 최대 2이미지 |
| partition_pdf | PyMuPDF 텍스트·표 추출 + 페이지 이미지 시각 분석 | 시각 분석 기본 앞 3페이지, 최대100. 전문 OCR와 동일하지 않음 |
| RAPTOR | UMAP 차원 축소 + GMM/BIC + 최대3층 요약 | 최대120청크. 요약당 입력을 묶음으로 제한. 원문 연결 유지. 전역 후 지역 군집을 모두 복제한 구현은 아님 |
| Chain of Density | 빠진 정보를 보완하는 5회 로컬 요약 | 원문12,000자 이하, 동일 단어 수 엄격 보장 없음 |
| LangSmith 추적 | 외부 추적 비활성화, JSON 실행 기록 제공 | 외부 계정에 문서 보내지 않음 |
| 토큰·비용 모니터링 | 유료 API 호출 차단 | OpenAI 청구 비용 추정은 필요 없음 |

여러 모델 공급자를 나열한 원본의 모든 모델을 설치하지 않았습니다. HuggingFaceHub/구형 GPT 등 개별 공급자 비교 대신 같은 역할의 무료 로컬 모델을 사용합니다. 원본의 스트리밍 편의 함수 대신 답변 완성 후 표시하여 근거를 분리합니다.

파일당 30MB·전체1GB는 업로드 허용값입니다. 실제1GB 자료로 성능을 검증한 것은 아니며 텍스트 양·PDF 구조·메모리에 따라 나눠 처리해야 할 수 있습니다. 생성 모델에 보내는 근거는 총5000자 범위로 제한하고 화면에 해당 발췌를 표시합니다. RAPTOR 검색 결과의 일부 원문만 답변 길이 범위 내에서 선택됩니다.

이미지 설명, 요약, 대화 재작성, 답변은 모델의 생성 결과이므로 틀릴 수 있습니다. 특히 실제 로컬 검증에서 후속 답변이 과제 예시 개수를 부정확하게 다시 표현한 사례가 있어, 근거 대조를 유지합니다. 번호 유효성 검사로 잘못된 번호는 안내하지만 의미적 정확성을 자동 보증하지는 않습니다.
