# 처음 실행하는 조원용 안내

이 폴더의 README.md에 설치부터 실행까지 정리했습니다.

1. Windows 10/11 x64에 Python 3.12 64비트를 설치합니다. Python launcher도 설치하세요.
2. GitHub에서 저장소를 ZIP으로 내려받고 **압축을 풉니다**.
3. `week2-mini-chatbot/임지민` 폴더로 이동합니다.
4. `setup_windows.bat`를 실행합니다. 최초 설치에는 인터넷과 수 GB 이상의 여유 공간이 필요합니다.
5. 완료되면 `run_chatbot.bat`를 실행합니다.
6. 로컬 AI 답변을 선택하고, 샘플 체크를 유지한 채 **문서 인덱스 만들기**를 누릅니다.
7. `2주차 과제 제출물은 무엇인가요?`라고 질문합니다.

API 키, OpenAI 계정, 결제는 필요 없습니다. 필요한 Python 패키지와 공개 로컬 모델은 설치 스크립트가 다운로드합니다. 모델 파일과 가상환경은 GitHub에 넣지 않았습니다.

자체 문서로 실행하려면 샘플 체크를 해제하고 파일을 업로드하거나 글을 붙여넣으세요. 문서와 설정을 바꾸면 인덱스를 다시 만들어야 합니다.

실습 노트북은 `run_notebook.bat`로 열고 위에서부터 실행하세요. 기본 실습은 검색 데모로 시작합니다. `DEMO=False`로 바꾸면 로컬 AI를 사용합니다.
