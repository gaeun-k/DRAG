# 2주차 — 기본 RAG 파이프라인 구현

## 학습 목표
LangChain으로 기본 텍스트 RAG 파이프라인을 직접 구현한다.

## 학습 내용
- 문서 청킹 전략
- 프롬프트에 검색 결과 결합하는 방식
- 간단한 QA 챗봇 구현

## 과제
자체 문서(위키/블로그 등)로 미니 RAG 챗봇 구현
(테디노트 GitHub `12-RAG` 예제 코드를 베이스로 수정 — 처음부터 직접 구현하지 않아도 됨)

## 진행 방식
전원 각자 미니 RAG 챗봇을 구현해온 뒤, 세션에서 모여 디버깅 및 이슈 공유
(역할 분담 없이 각자 전체 파이프라인을 직접 구현)
