# 3주차 — 고급 리트리벌 기법 및 평가

## 학습 목표
검색 품질을 높이는 고급 기법과 RAG 성능 평가 방법을 이해한다.

## 학습 내용
- Self-RAG, HyDE, Reranking 개념
- RAGAS 기반 RAG 평가 지표(정확도, 충실도 등)

## 과제
2주차 챗봇에 Reranking 적용 후 성능 비교

## 진행 방식
전원 발표자료와 실습 코드를 미리 준비해오고, 세션 당일 사다리타기로 발표자 1인을 선정해 발표 진행
발표자 외 전원은 준비해온 내용을 바탕으로 질문 및 코드 비교
