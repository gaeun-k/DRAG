# 4주차 — SigLIP 중심 비전-언어 임베딩 학습

## 학습 목표
SigLIP의 구조와 특징을 중심으로 비전-언어 임베딩 모델을 이해한다.

## 학습 내용
- SigLIP 구조 및 대조학습(contrastive learning) 방식 학습
- SigLIP이 이미지-텍스트 검색에 적합한 이유 이해

## 과제
SigLIP으로 이미지 임베딩 추출 실습

## 진행 방식
전원 발표자료와 실습 코드를 미리 준비해오고, 세션 당일 사다리타기로 발표자 1인을 선정해 발표 진행
발표자 외 전원은 준비해온 내용을 바탕으로 질문 및 코드 비교
