# 6주차(선택) — 통합 미니 프로젝트

## 학습 목표
텍스트 RAG와 멀티모달 검색을 통합한 데모를 완성하고 발표한다.

## 학습 내용
- 팀 전체가 통합 데모 시나리오 설계 (예: 텍스트 질의로 이미지+문서 함께 검색)
- 결과물 발표 및 피드백

## 과제
통합 미니 프로젝트 데모 및 발표 자료

## 진행 방식
6인을 3인씩 2개 팀으로 나누어, 각 팀이 텍스트+이미지 통합 검색 데모를 처음부터 끝까지 함께 완성
(역할 고정 없이 팀 내에서 자율 분담) + 마지막에 두 팀 결과물을 비교·발표

## 폴더 구조
`team1`, `team2` 폴더에 각 팀의 통합 데모 코드와 발표 자료를 정리합니다.
